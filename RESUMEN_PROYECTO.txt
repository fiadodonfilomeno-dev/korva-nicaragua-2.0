====================================
BASES DE DATOS Y MODELOS
====================================

Profile
  - Extiende el modelo User de Django
  - business_name, logo, banner, ruc
  - verified, city, sector
  - popularity_score
  - followers_count, associates_count
  - Método tier() para calcular nivel dinámico

Post
  - title, content, author (FK Profile)
  - tags (ManyToMany via taggit)
  - upvotes, downvotes
  - moderation_status

Product
  - name, description, price
  - currency (NIO/USD)
  - category (Ventas/Compras)
  - contact_whatsapp
  - views_count

Message
  - sender, recipient (FK Profile)
  - content, timestamp
  - read_status

AIConversation & AIMessage
  - Historial de chats con IA

AnalyticsReport
  - total_posts, total_products
  - Estadísticas mensuales

CÓMO EJECUTAR
====================================

1. Navegar a la carpeta del proyecto:
   cd C:\Users\harif\Desktop\Korva2.0

2. Instalar dependencias:
   pip install -r requirements.txt

3. Ejecutar migraciones (ya hechas):
   python manage.py migrate

4. Iniciar el servidor:
   python manage.py runserver

5. Acceder a:
   http://127.0.0.1:8000

6. Panel de administración:
   http://127.0.0.1:8000/admin
