## 🔧 SI ALGO NO FUNCIONA

### Problema: No puedo conectar
**Solución:**
1. Asegúrate que escribiste correctamente: `http://localhost:8000`
2. Intenta: `http://127.0.0.1:8000`
3. Verifica que no haya espacios extras

### Problema: El servidor se cerró
**Solución:**
Ejecuta este comando en la terminal:
```bash
cd "C:\Users\harif\Desktop\Korva2.0"
python manage.py runserver
```

### Problema: Página en blanco
**Solución:**
1. Presiona F5 para refrescar
2. Limpia el caché: Ctrl+Shift+Delete
3. Intenta en modo incógnito
